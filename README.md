# M2MTools

Редактор вариантов для преобразования автоматов Мили и Мура.

## Работа с автоматом

1. Выберите направление преобразования и номер варианта.
2. Загрузите изображение задания: нажмите область изображения или перетащите
   в неё PNG, JPEG, BMP либо WebP размером до 10 МБ.
3. Выберите способ редактирования:
   - **Таблица переходов** — задайте списки состояний и сигналов, затем
     заполните переходы.
   - **Реакция автомата** — каждый столбец описывает один такт:
     текущее состояние, входной сигнал, следующее состояние и выходной сигнал.
     Списки `A`, `X` и `Y` пополняются автоматически.
4. Сохраните вариант. Незаполненные или противоречивые данные подсвечиваются;
   подробное объяснение показывается рядом с редактором и во всплывающей
   подсказке ячейки.

Таблица переходов и реакция синхронизируются сразу после корректного
изменения. Для автомата Мили выход относится к переходу, для автомата Мура —
к состоянию, в которое выполнен переход.

В окне **Открыть варианты** можно загрузить или удалить вариант, а также
поменять местами два номера. Один из номеров при обмене может быть свободным.
После удаления с разрывом в нумерации приложение предлагает сдвинуть
следующие варианты.

Кнопка **Экспорт BazaVar** проверяет все варианты и сохраняет переносимый
архив `.m2m`. Архив зашифрован AES-256-GCM; ключ получается из заданного
пользователем пароля через PBKDF2. **Открыть BazaVar** сначала полностью
расшифровывает и проверяет архив и только затем атомарно заменяет текущую
базу. Пароль в базе и в файлах проекта не сохраняется.

Изображение хранится в SQLite вместе с вариантом, поэтому исходный файл после
сохранения не требуется. Существующие базы автоматически получают новые поля
для изображений при первом запуске обновлённой версии.

## Сборка

Требуются CMake 3.16+, компилятор C++17, OpenSSL 1.1.1+ и Qt 6 с модулями
Widgets, Sql и LinguistTools.

```bash
cmake -S . -B build
cmake --build build --target M2MTools
```

При запуске рядом с рабочим каталогом создаётся или открывается
`variants.db`.
